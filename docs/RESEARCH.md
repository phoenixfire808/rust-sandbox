- Static code review found the board visual wheel bottom sat 56 mm below its transform origin while spawn placed that origin 126 mm above ground and support rays originated at the deck center with a 126 mm rest length. Changed authored suspension to 14 mm, moved probes to wheel axles, set ray rest length to wheel radius plus suspension, and spawn the board with 4 mm initial wheel clearance. - The seated rider root previously discarded the board's pitch/roll, leaving the rider visually detached during board rotation. It now follows the board rigid orientation with regular/goofy seat yaw. This is a rigid attachment approximation only. Per-foot IK, rider/board separation, animation timing and captured pose remain unimplemented.
- Blocked vehicle exit completion previously cleared the pending exit target and restored entry timing, which could send the player back onto the board. A blocked completed exit now releases at the original mount point if that point remains clear; if both positions are obstructed it retains the completed exit state and retries rather than restarting entry. This is a static code finding, not a reproduced gameplay observation.
- Changed the skateboard's selected idle pose away from a pistol hold to the existing generic melee hold. This avoids a firearm posture; it is not a skate-specific rider animation. Reference stills do not provide pose or animation-clip evidence.
